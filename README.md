# DACreator
为头文字D：激斗设计的python程序，可以自动爬取arcadezone网页的计时赛成绩，并生成易于阅读的表格。

B站演示视频<https://www.bilibili.com/video/BV13SFWzTEnv/>
# 快速开始
## 环境要求
- Python 3.7 +
## 原数据文件
如果需要用本地文件生成图片，需要符合以下格式，并保存为csv格式
```csv
コース,ルート,タイム,タイム評価,記録車種,全国順位,記録日
秋名湖,左周り,2'27"760,EXPERT,CIVIC TYPE R (FL5) [HC],255位,2026/01/19
秋名湖,右周り,2'28"702,EXPERT,CIVIC TYPE R (FL5) [HC],121位,2025/12/21
...
```
### 克隆仓库
```shell
https://github.com/GuitaristRin/DACreator.git
```
```shell
cd DACreator
```
### 配置用户数据
用文本编辑器编辑目录下的***Player_id.dat***，输入自己的信息（支持全角或半角用户名）。
### 安装依赖
```shell
pip install -r requirements.txt
```
### 执行程序
```shell
python core.py
```
### 选择功能
进入程序后，输入1并回车以利用爬虫爬取网页数据，在此期间请耐心等待并保持网络畅通，输入2则为本地csv版本。

# 注意事项
## 1.关于评级与排名
在线爬取的成绩等级与全国排名直接取自 arcadezone 服务器返回的数据（eval_id 与 rank 字段），无需维护本地评级库。
## 2.关于重名玩家
游戏不要求用户名唯一，同一用户名可能对应多名玩家。在线爬取会保留同名玩家的全部成绩（各带自己的排名）。

注意：搜索接口会在单次请求中返回该用户名的全部匹配记录，实测最大命中数为 479 条、未触发截断（真实榜单中同名玩家最多约 18 人）。若未来同名玩家数量激增并超过服务器的单次返回上限，可能出现漏报，届时应关注接口行为变化。
